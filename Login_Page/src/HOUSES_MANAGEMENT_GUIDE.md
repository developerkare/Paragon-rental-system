# Houses Management Guide

## Overview
The **Houses Management** page is your centralized hub for managing all properties and their units. This streamlined interface makes it easy to add multiple houses/apartments and configure rental units for each property.

## Accessing Houses Management

Navigate to the **Houses** link in the main navigation bar to access the Houses Management page.

## Key Features

### 1. **Add Multiple Properties**
- Click the **"Add House/Property"** button to add new properties
- Fill in property details including:
  - Property name
  - Description
  - Address
  - Number of units
  - Property image (upload or URL)
- Add as many properties as you manage

### 2. **View Property Status**
Each property card displays:
- Property image and description
- Configuration status badge:
  - ✅ **Units Setup** (green) - Units are configured
  - ⚠️ **No Units** (orange) - Units need to be configured
- Quick action buttons for managing units

### 3. **Configure Units for Each Property**
- Click **"Setup Units"** or **"Manage Units"** on any property card
- You'll be taken to the Units configuration page for that specific property
- Set up unit details:
  - Unit number/name
  - Unit type (3-bedroom, 2-bedroom, bedsitter, etc.)
  - Base rent amount
  - Additional charges (water, electricity, etc.)
  - Unit status (occupied/vacant)

### 4. **Statistics Dashboard**
The page displays key metrics:
- **Total Properties** - All houses you manage
- **Units Configured** - Properties with units set up
- **Needs Setup** - Properties still requiring unit configuration

### 5. **Search & Filter**
- Use the search bar to find properties by name or description
- Quickly locate specific properties in your portfolio

## Workflow

### For New Properties:
1. **Add Property** → Click "Add House/Property"
2. **Fill Details** → Enter property information and save
3. **Setup Units** → Click "Setup Units" on the property card
4. **Configure Units** → Add all rental units with their details
5. **Manage Tenants** → Once units are configured, you can add tenants

### For Existing Properties:
1. **View All Properties** → Navigate to Houses Management
2. **Manage Units** → Click "Manage Units" on any property
3. **Edit/Add Units** → Modify existing units or add new ones
4. **Go Back** → Return to Houses Management to select another property

## Benefits

✅ **Centralized Management** - All properties in one place  
✅ **Clear Status** - Instantly see which properties need unit configuration  
✅ **Streamlined Workflow** - Add multiple properties before configuring units  
✅ **Easy Navigation** - Jump between properties and unit management seamlessly  
✅ **Role-Based Access** - Managers see only their assigned properties (caretakers)

## Important Notes

- You must configure units for a property before you can add tenants to it
- The "Configure Units Now" button in the Tenants page will take you to unit configuration
- Each property can have multiple units with different configurations
- Units can have optional charges that tenants can choose to use
- Deleting a property will remove all associated units and tenant data

## Next Steps

After setting up your properties and units:
1. Navigate to **Tenants Mgmt** to add tenants to your configured units
2. Use **Financial Reports** to track income from all properties
3. Visit **Advertisements** to promote vacant units
4. Manage staff access through **User Management**
