# Caretaker System Guide

## Role Overview

**Role Type:** On-site operations & reporting  
**Access Level:** Limited task-based access

## System Duties

### 1. Report Maintenance Issues
- Report maintenance issues through the system
- Specify priority level (Low, Medium, High, Urgent)
- Provide detailed descriptions and location information
- Upload photos/videos of the issue
- Track status of reported issues

### 2. Receive and Update Assigned Maintenance Tasks
- View all assigned maintenance tasks
- See task details including priority, location, and due dates
- Update task status: Pending → In Progress → Completed
- Add notes and comments to tasks
- Upload completion photos/videos

### 3. Upload Photos/Videos
Caretakers can upload visual documentation for:
- **Repairs:** Before and after photos of maintenance work
- **Inspections:** Condition photos during inspections
- **Property Condition:** Regular documentation of property state
- **Incidents:** Evidence for reported incidents

### 4. Conduct Move-in and Move-out Inspections
- Perform move-in inspections for new tenants
- Conduct move-out inspections when tenants leave
- Document property condition with photos/videos
- Record inspection findings and notes
- Track inspection history

### 5. Record Utility Meter Readings
- Record water meter readings
- Record electricity meter readings
- Record gas meter readings
- Upload meter photos for verification
- Track reading history by unit/location

### 6. Enforce House Rules On-site
- Monitor property compliance
- Report rule violations through the system
- Document violations with photos/videos
- Track violation history

### 7. Report Incidents and Emergencies
Report various types of incidents:
- **Emergency:** Immediate safety concerns
- **Rule Violation:** Tenant violations of property rules
- **Complaint:** General property complaints
- **Other:** Miscellaneous incidents

For each incident, specify:
- Severity level (Low, Medium, High, Critical)
- Detailed description
- Location
- Supporting evidence (photos/videos)

### 8. Update Task Status
Track task progress through three states:
1. **Pending:** Task assigned but not started
2. **In Progress:** Actively working on the task
3. **Completed:** Task finished and verified

## System Access Restrictions

### ✅ What Caretakers CAN Do:
- Report and track maintenance issues
- Update assigned maintenance tasks
- Upload photos/videos for documentation
- Conduct property inspections
- Record utility meter readings
- Report incidents and emergencies
- View their own profile and settings
- Change their password

### ❌ What Caretakers CANNOT Do:
- Access financial data or payments
- View properties not assigned to them
- Create or manage tenant accounts
- Approve budgets or expenditures
- Access user management
- View financial reports
- Delete system data
- Modify property listings

## Best Practices

### Reporting Maintenance Issues
1. Report issues as soon as they're discovered
2. Set appropriate priority levels
3. Provide detailed, clear descriptions
4. Include location information (building, unit number)
5. Upload photos/videos when possible
6. Follow up on reported issues

### Updating Tasks
1. Start tasks promptly
2. Update status regularly
3. Add notes about progress
4. Upload completion photos
5. Mark as complete when finished
6. Communicate any delays or issues

### Conducting Inspections
1. Follow inspection checklists
2. Document everything with photos
3. Note any damage or issues
4. Record utility meter readings
5. Complete inspection forms thoroughly
6. Submit findings promptly

### Recording Utility Readings
1. Record readings on scheduled dates
2. Upload meter photos for verification
3. Double-check readings for accuracy
4. Note any unusual readings
5. Report meter malfunctions

### Reporting Incidents
1. Report emergencies immediately
2. Set appropriate severity levels
3. Include all relevant details
4. Upload evidence (photos/videos)
5. Follow safety protocols
6. Notify management of critical incidents

## Photo/Video Upload Guidelines

### Accepted Formats
- PNG, JPG for photos
- MP4 for videos
- Maximum file size: 10MB per file

### Best Practices
- Take clear, well-lit photos
- Capture multiple angles
- Include context in photos
- Date/timestamp photos when possible
- Organize photos by task/inspection
- Keep backup copies

## Priority Levels

### Maintenance Issues & Tasks
- **Low** - Minor issues, no urgency
- **Medium** - Standard priority, address within normal timeframe
- **High** - Important issues requiring prompt attention
- **Urgent** - Critical issues requiring immediate action

### Incidents
- **Low** - Minor incidents, no immediate impact
- **Medium** - Standard incidents requiring attention
- **High** - Serious incidents requiring prompt response
- **Critical** - Emergency situations requiring immediate action

### Common Questions

**Q: What if I can't complete a task on time?**
A: Add a note to the task explaining the delay and notify management through the system.

**Q: How do I report an emergency?**
A: Use the "Report Incident" quick action, select "Emergency" type, and set severity to "Critical".

**Q: Can I see tasks for other caretakers?**
A: No, you can only see tasks assigned to you.

**Q: How long are photos/videos stored?**
A: All uploaded media is stored permanently for documentation purposes.

**Q: What if I make a mistake in a report?**
A: Contact management to request corrections. Keep detailed notes.
