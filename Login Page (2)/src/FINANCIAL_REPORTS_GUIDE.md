# Financial Reports & Analytics - User Guide

## Overview
The Financial Reports & Analytics page provides comprehensive income tracking, payment history analysis, and detailed financial insights from all your properties. This powerful tool replaces the basic "Account Statistics" section with a full-featured reporting system.

## Accessing Financial Reports

**From Profile Page:**
1. Login to your account
2. Click on your profile picture (top right) → Select "Profile"
3. Scroll down to see the **"Financial Reports & Analytics"** card
4. Click the card to open the reports page

**Quick Access:**
- The Financial Reports card is prominently displayed on your profile page
- Features a blue gradient icon with chart symbol
- Shows key features: Revenue Tracking, Advanced Filters, Export Reports

## Key Features

### 📊 Summary Statistics (Top Cards)

Four key metrics displayed at the top:

1. **Total Revenue**
   - Sum of all filtered payments
   - Green icon with dollar sign
   - Updates based on filters

2. **Total Payments**
   - Number of payment transactions
   - Blue icon with document
   - Counts all filtered records

3. **Average Payment**
   - Average amount per payment
   - Purple icon with trending arrow
   - Calculated from filtered data

4. **Properties**
   - Number of unique properties
   - Orange icon with house
   - Based on payment data

### 🔍 Advanced Filters

Comprehensive filtering options:

#### Search
- **Search by:** Tenant name, unit number, transaction ID, or amount
- **Real-time:** Results update as you type
- **Case insensitive:** Finds matches regardless of case

#### Property/Apartment Filter
- Select specific property or "All Properties"
- Dropdown populated from your apartment list
- Filters payments by apartment/unit

#### Payment Method Filter
- Options: All, Cash, Bank Transfer, Online Payment, Check
- See revenue breakdown by payment type
- Track payment method preferences

#### Date Range
- **From Date:** Start of date range
- **To Date:** End of date range
- Leave blank for all-time data
- Useful for monthly/quarterly reports

#### Payment Status
- Options: All, Claimed, Unclaimed, Pending
- Track payment collection status
- Identify unclaimed payments

#### Clear All Button
- Instantly reset all filters
- Return to viewing all data
- Located at top-right of filters section

### 📑 Multiple View Tabs

#### 1. All Payments Tab
**Detailed payment table showing:**
- Date of payment
- Tenant name
- Unit number
- Amount (in green)
- Payment method
- Status (with colored badges)
- Transaction ID

**Features:**
- Scrollable table for large datasets
- Color-coded status badges
- Total amount summary at bottom
- Shows filtered record count in header

#### 2. By Property Tab
**Grouped view by property:**
- Each property in its own card
- House icon for visual identification
- Shows:
  - Property name
  - Number of payments
  - Total revenue
  - Average payment amount
- Progress bar showing percentage of total revenue
- Sorted by revenue contribution

#### 3. By Month Tab
**Monthly revenue breakdown:**
- Table format with three columns:
  - Month (formatted as "January 2024")
  - Revenue amount
  - Percentage of total
- Sorted newest to oldest
- Easy to spot revenue trends
- Identify seasonal patterns

#### 4. By Method Tab
**Payment method analysis:**
- Card-based layout
- Each payment method shown separately
- Displays:
  - Method name
  - Total amount
  - Percentage of total revenue
- Helps understand payment preferences
- Useful for accounting reconciliation

### 📄 Export & Print Functions

#### Export to CSV
**Button:** "Export CSV" (top right)

**Exported data includes:**
- Date
- Tenant name
- Unit number
- Amount
- Payment method
- Status
- Transaction ID
- Notes

**File format:**
- CSV (Comma-Separated Values)
- Opens in Excel, Google Sheets, etc.
- Filename: `financial-report-YYYY-MM-DD.csv`
- Includes filtered data only

**Use cases:**
- Import into accounting software
- Create custom reports in Excel
- Archive records
- Tax preparation
- Audit trails

#### Print Report
**Button:** "Print Report" (top right)

**Printed report includes:**
- Header with title and generation date
- Date range (if filtered)
- Summary statistics (3 cards)
- Complete payment details table
- Total row with summary
- Professional formatting

**Features:**
- Opens in new window/tab
- Print-optimized layout
- Hides buttons when printing
- Shows filtered data only
- Buttons: Print, Close

**Use cases:**
- Physical file copies
- Landlord reports
- Investor presentations
- Monthly statements
- Tenant records

## Common Use Cases

### 📅 Monthly Revenue Report

**Steps:**
1. Set **From Date** to first day of month (e.g., "2024-10-01")
2. Set **To Date** to last day of month (e.g., "2024-10-31")
3. Click **"By Property"** tab
4. Review revenue by property
5. Click **"Export CSV"** or **"Print Report"**

### 🏢 Property Performance Analysis

**Steps:**
1. Select specific property from dropdown
2. Set date range (e.g., last 6 months)
3. Click **"By Month"** tab
4. Analyze monthly trends
5. Compare with other properties

### 💰 Cash vs Digital Payments

**Steps:**
1. Clear all filters
2. Click **"By Method"** tab
3. Compare cash vs other methods
4. Use for accounting reconciliation
5. Track payment method trends

### 🔍 Find Specific Transaction

**Steps:**
1. Enter transaction ID in search box
2. Or search by tenant name
3. View in **"All Payments"** tab
4. Check details and status
5. Print single transaction if needed

### 📊 Year-End Financial Summary

**Steps:**
1. Set **From Date:** January 1
2. Set **To Date:** December 31
3. Review all tabs for complete picture:
   - All Payments: Complete list
   - By Property: Property breakdown
   - By Month: Monthly trends
   - By Method: Payment analysis
4. Export CSV for tax records
5. Print report for files

### 🚨 Unclaimed Payments Review

**Steps:**
1. Set **Status** filter to "Unclaimed"
2. Review unclaimed payments list
3. Sort by date to find oldest
4. Take action to assign payments
5. Re-run report to verify

## Understanding the Data

### Payment Status Badges

- **Claimed** (Blue/Default): Payment assigned to tenant
- **Unclaimed** (Red): Payment received but tenant unknown
- **Pending** (Gray): Payment processing or verification needed

### Revenue Calculations

**Total Revenue:**
- Sum of all payment amounts
- Filtered by selected criteria
- Displayed in green throughout

**Average Payment:**
- Total Revenue ÷ Number of Payments
- Rounded to 2 decimal places
- Useful for pricing analysis

**Percentage Breakdowns:**
- Each category shows % of total
- Helps identify major revenue sources
- All percentages sum to 100%

## Best Practices

### Regular Reporting
✅ **Do:**
- Run monthly reports for each property
- Export CSV for monthly backups
- Review unclaimed payments regularly
- Track payment method trends
- Keep printed reports for tax season

❌ **Don't:**
- Ignore unclaimed payments
- Forget to export important data
- Skip regular reconciliation
- Overlook seasonal trends

### Data Accuracy
✅ **Do:**
- Ensure all payments are properly recorded
- Verify transaction IDs
- Update payment status promptly
- Match payments to correct properties

❌ **Don't:**
- Leave payments as "pending" indefinitely
- Skip transaction IDs
- Assign wrong units to payments

### Security & Privacy
✅ **Do:**
- Log out when finished
- Print sensitive reports securely
- Store exports in secure locations
- Limit access to authorized users

❌ **Don't:**
- Leave reports visible
- Share export files unsecurely
- Print on public printers

## Tips & Tricks

### Quick Filters
- Use keyboard to type in search instantly
- Tab through filter fields quickly
- Click "Clear All" to start fresh

### Date Shortcuts
- Leave "From Date" blank for all historical data
- Leave "To Date" blank for current day
- Use first/last of month for monthly reports

### Reading the Progress Bars
- In "By Property" tab, longer bar = more revenue
- Quick visual comparison of properties
- Helps identify top performers

### Export Strategy
- Export monthly for regular backups
- Use descriptive filenames when saving
- Keep exports organized by year/month

### Print Optimization
- Use "Print Preview" before printing
- Adjust print settings for best results
- Consider PDF printing for digital storage

## Troubleshooting

**No data showing:**
- Check if filters are too restrictive
- Click "Clear All" to reset
- Verify payments exist in system

**Wrong totals:**
- Check date range filters
- Verify property filter selection
- Ensure all payments are recorded

**Export not working:**
- Check browser popup blocker
- Try different browser
- Ensure download permissions

**Print shows blank:**
- Check printer connection
- Try "Print to PDF" first
- Refresh page and try again
